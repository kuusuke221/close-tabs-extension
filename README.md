# ピン留め以外をすべて閉じる（グループ化対応版）

現在開いているウィンドウの中で、**「ピン留め（固定）されたタブ」**および**「グループ化されたタブ」**以外のすべてのタブを一括で閉じるGoogle Chrome拡張機能です。

## 主な機能

- **ピン留め・グループ以外のタブを一括削除**: 固定している重要なタブや、カテゴリごとにまとめているタブグループを残したまま、散らかった一時的なタブだけをすばやく整理できます。
- **2通りの実行方法**:
  1. **右クリックメニュー**: Webページ上を右クリックしてメニューから実行できます。
  2. **拡張機能アイコン**: ツールバーのアイコンをクリックするだけで実行できます。

---

## インストール方法（開発者モードでの読み込み）

現在、本機能はパッケージ化されていない拡張機能としてローカルから読み込むことができます。

1. 本リポジトリをZIP形式でダウンロードし、任意の場所に解凍します（または `git clone` します）。
2. Google Chrome を開き、アドレスバーに `chrome://extensions/` と入力して拡張機能管理画面を開きます。
3. 画面右上にある **「デベロッパー モード」** を有効（オン）にします。
4. 画面左上の **「パッケージ化されていない拡張機能を読み込む」** ボタンをクリックします。
5. 解凍したフォルダ（`manifest.json` が入っているフォルダ）を選択して読み込みます。

---

## 使い方

### 1. 右クリックメニューから実行する
Webページ上の何もない場所で右クリックし、メニューから **「ピン留め・グループ以外のタブを閉じる」** をクリックします。

### 2. 拡張機能アイコンから実行する
Chromeのツールバー（拡張機能メニュー内）にある、この拡張機能のアイコンをクリックします。

---

## 動作イメージ

- **閉じられないタブ (保護されるタブ):**
  - ピン留め（固定）されているタブ
  - タブグループに含まれているタブ
- **閉じられるタブ:**
  - 上記以外の、個別に開かれている通常のタブ
